    Bubblesort

    1. Implementieren Sie eine Funktion bubblesort [#]_, der ein Sequenztyp (List, String) zum Sortieren übergeben werden kann.

    Hinweis Bubble Sort ist ein Sortier-Algorithmus nur für die Lehre, seine Performance ist lausig, nämlich O(n²)! Informieren Sie sich im Web [#]_, wie er funktioniert!

    Aus diesem Hinweis ergibt sich gleich auch der 2. Aufgabenteil:

    1. Vergleichen Sie die Performance des von Ihnen programmierten Sortieralgorithmus mit dem in |py| "eingebauten" Algorithmus für verschieden große Listen!

      Hierzu ein Hinweis: Sie können ganz einfach Einmalmessungen durchführen, indem Sie time.time() verwenden. Genauer wird's aber, wenn Sie die Messungen mehrmals durchführen, wozu Sie den von Ihnen programmierten :ref:seminars.Q:(?) Runtime-Meter verwenden könnten.

    class Algorithms:

    """Namespace (= eine Klasse, die nur der Strukturierung der Software dient), der mehrere Algorithmen zusammenfasst.

    Usage:
        ```python
        for N in ( 5, 10, 100, 200, 300):
            L = [ random.randint( -N, N) for _ in range( N)]

            bubblesorter = Algorithms.Bubblesorter( L)
            rtm_bubblesorter = pT.PieRuntimemeter( "%s( %d)" % (bubblesorter.__class__.__name__, N))

            builtinsorter = Algorithms.BuiltInSorter( L)
            rtm_builtinsorter = pT.PieRuntimemeter( "%s( %d)" % (builtinsorter.__class__.__name__, N))

            for _ in range( N):
                with rtm_bubblesorter:
                    bubblesorter.list_sorted()

            rtm_bubblesorter.report( print)

            for _ in range( N):
                with rtm_builtinsorter:
                    builtinsorter.list_sorted()

            rtm_builtinsorter.report( print)

            print()
        ```
    """

    class Bubblesorter:

        """Bubblesort, der "didaktische Sortierer".

        PARAMETERS:
            list_unsorted (sequence):
                Sortiert kann alles werden, das eine Sequenz und - wichtig - *mutable* ist.
                Wir werden hier also vornehmlich Listen erwarten müssen, denn Strings und Tuples
                können wir nicht in-place ändern.
        """
        def __init__( self, list_unsorted):
            self.__list_unsorted = list_unsorted
            return

        def list_sorted( self):
            """
            """
            L = self.__list_unsorted[ :]
                                            # Die unsortierte Liste muss erhalten bleiben, weshalb
                                            #   wir sie hier kopieren. Die Schreibweise hier ist
                                            #   eine "alte", mittlerweile bringt die ``list`` eine
                                            #   Methode ``copy`` mit.
            while True:
                still_unsorted = False
                for i in range( 1, len( L)):
                    if L[ i-1] > L[ i]:
                        L[ i-1], L[ i] =  L[ i], L[ i-1]
                        still_unsorted = True

                if not still_unsorted:
                    break

            return L

        def list_unsorted( self):
            """
            """
            return self.__list_unsorted


    class BuiltInSorter:

        """Das eingebaute ``sorted``.

        PARAMETERS:
            list_unsorted (sequence):
                Sortiert kann alles werden, das eine Sequenz und - wichtig - *mutable* ist.
                Wir werden hier also vornehmlich Listen erwarten müssen, denn Strings und Tuples
                können wir nicht in-place ändern.
        """
        def __init__( self, list_unsorted):
            self.__list_unsorted = list_unsorted
            return

        def list_sorted( self):
            """Verwendet ``sorted``.

            Wenn Sie hier die Liste in-place sortieren möchten, müssen Sie die unsortierte Liste
            "retten", indem Sie eine Kopie -in-place sortieren. Das ist einfach, denn mittlerweile
            bringt die ``list`` eine Methode ``copy`` mit.
            """
            return sorted( self.__list_unsorted)

        def list_unsorted( self):
            """
            """
            return self.__list_unsorted

    Christbaum - Musterlösung

    Ein Lösung könnte so aussehen:

    def christbaum( hoehe_gruen, hoehe_braun, c="*"):
    s = ""
    for i in range( hoehe_gruen):
        s += " " * (hoehe_gruen - 1 - i) + c * (2*i + 1) + "\n"

    for i in range( hoehe_braun):
        s += " " * (hoehe_gruen - 1) + c + "\n"

    return s

print( christbaum( 9, 4))

def find_first_unique_char( text):
    for i, c in enumerate( text):
        if text.count( c) == 1:
            print( c, "an der Stelle", i, "kommt nur 1-mal vor im gegebenen Text.")

    Neun

    Schreiben Sie eine Funktion, die angibt, wie viele Neunen es in der Zahlenreihe von 1 bis 100, 1 bis 1000 usw. gibt!

    Neun - Musterlösung

    Eie Lösung könnte so aussehen:

    def Neunen( von: int, bis: int):
    n = 0
    for i in range( von, bis + 1):
        n += str( i).count( "9")

    return n

print( Neunen( 0, 100))     # 20
print( Neunen( 0, 1000))    # 300

    import sys, time

def pgen( on_prime_found: callable): ####### FGE #######
    ''' ... generates the sequence of all primes: 2,3,5,7,11 ... 
    '''

    p=2
    f=1

    try:

        ts2=time.time()

        while(True):

            if f%p%2: 
                sys.stdout.write(str(p)+"\n")
                on_prime_found( p) ####### FGE #######
            p+=1
            f*=(p-2)

    except:

#   raise KeyboardInterrupt .. Ctrl-C

        ts2-=time.time()
        sys.stderr.write("time: "+str(round(-ts2,3))+" sec\n")

def main():
    pgen( print) ####### FGE #######
    sys.exit()

if __name__=="__main__":
    main()

    Zahlendreher

    Schreiben Sie eine Funktion, die eine Ganzzahl mit eventuellem Minuszeichen entgegennimmt und den Zahlenwert umdreht. Aus 42 wird also 24, aus -42 wird -24.

    Zeigen Sie, dass das Programm für beliebig große Zahlen funktioniert.

    Zahlendreher - Musterlösung

    Eine Lösung könnte so aussehen:

    import sys


def reversed_number( number):
    signum = -1 if number < 0 else 1
    typ = type( number)
                                    # Ist es sinnvoll, auf den Typ einzugehen? Welche(r) Typ(en)
                                    #   kommen eigentlich in Frage?
    reversed_number = signum * typ( str( abs( number))[::-1])
    return reversed_number

for value in ( 24, -24, sys.float_info.max):
    reversed_number( 42)
    print( "%s reversed is %s." % (value, reversed_number( value)))
