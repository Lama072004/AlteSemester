    Multithreading

    Multithreading ist Segen und Fluch zugleich.

    Segen, weil Multithreading es uns erlaubt,

    • performantere Programme, v.a. aber
    • besser strukturierte Programme

    zu schreiben.

    Fluch, weil Nebenläufigkeit auch die Komplexität erhöht. Zusätzlich verhalten sich diese Programme bei jedem Lauf anders, je nachdem, was die einzelnen Threads mit den von ihnen verwalteten Ressourcen (andere Prozesse, Files, I/Os) machen. Denn diese Ressourcen werden ihrerseits ein Zeitverhalten aufweisen, das eben in jedem Lauf von jenem des letzten Laufs abweichen kann. Eine echte Herausforderung ans Debugging, wenn's mal klemmt.

    Auf der anderen Seite ist Multithreading mit Python unkompliziert, ja geradezu komfortabel in der Nutzung, was die Wahrscheinlichkeit, dass man Fehler macht, wieder reduziert und damit die Bereitschaft, Multithreading einzusetzen, steigert.

    class Consumer( threading.Thread):

    """Consumer der Aufgabenstellung *Producer - Consumer*.

    Aufgabenstellung:
        Schreiben Sie ein Programm, das einen Producer-Thread und einen Consumer-Thread
        realisiert.

        Der Producer produziert Zufallszahlen, die der Consumer konsumiert. Beide Threads
        sollen per `print` anzeigen, wenn produziert bzw. konsumiert worden ist.

        Realisieren Sie die Kommunikation der beiden Threads über eine Queue. Wie würden
        Sie sie in der Größe dimensionieren? Was tun Sie gegen Underflow (Angebotsverknappung,
        Queue leer) u/o Overflow (Überangebot, Queue ist voll)?
    """

    def __init__( self, cycletime, q: queue.Queue, start_immediatly):
        super().__init__( daemon=True)
        self.__cycletime = cycletime
        self.__queue = q
        self.__stop_is_requested = False
        if start_immediatly:
            self.start()

        return

    def run( self): # override
        """Thread-Body des Consumers.
        """
        while True:
            if self.__stop_is_requested:
                break

            try:
                value = self.__queue.get( block=True, timeout=1.0)

            except queue.Empty as err:
                print( "%s(): %s, i.e. Producer not ready." % (self.run.__qualname__, err))
                break # YOUR STRATEGY GOES HERE ;-)

            print( "%s(): Product consumed: %s." % (self.run.__qualname__, value))

            time.sleep( self.__cycletime)

    def stop( self):
        """Request(!) an Thread-Body, sich zu stoppen.
        """
        self.__stop_is_requested = True

    run()

    class Producer( threading.Thread):
    """Producer der Aufgabenstellung *Producer - Consumer*.

    Aufgabenstellung:
        Schreiben Sie ein Programm, das einen Producer-Thread und einen Consumer-Thread
        realisiert.

        Der Producer produziert Zufallszahlen, die der Consumer konsumiert. Beide Threads
        sollen per `print` anzeigen, wenn produziert bzw. konsumiert worden ist.

        Realisieren Sie die Kommunikation der beiden Threads über eine Queue. Wie würden
        Sie sie in der Größe dimensionieren? Was tun Sie gegen Underflow (Angebotsverknappung,
        Queue leer) u/o Overflow (Überangebot, Queue ist voll)?
    """

    def __init__( self, cycletime, q: queue.Queue, start_immediatly):
        super().__init__( daemon=True)
        self.__cycletime = cycletime
        self.__queue = q
        self.__stop_is_requested = False
        if start_immediatly:
            self.start()

        return

    def run( self): # override
        """Thread-Body des Producers.
        """
        while True:
            if self.__stop_is_requested:
                break

            value = random.uniform( -100, 100)
            print( "%s(): Product built, will try to deliver %s." % (self.run.__qualname__, value))
            dt = time.time()
            try:
                self.__queue.put( value, block=True, timeout=1.0)

            except queue.Full as err:
                print( "%s(): %s, i.e. Consumer not ready." % (self.run.__qualname__, err))
                break # YOUR STRATEGY GOES HERE ;-)

            dt = time.time() - dt
            print( "%s(): Product delivered (took %.3f s)." % (self.run.__qualname__, dt))
            time.sleep( self.__cycletime)

    def stop( self):
        """Request(!) an Thread-Body, sich zu stoppen.
        """
        self.__stop_is_requested = True

    run()
